# 主编决定（校对阶段统一执行）

## 来自 C 组（f14r–f16bv）

1. **f16bv 星图尺寸**：现在占位 82 mm（原比例约 115 mm）。等星图用 TikZ 重绘时再调整；必要时把一条脚注移到别处。
2. **miliarium**：用单 l 的 `miliaribus / miliarii`，这既是 1610 原文写法，也是古典拼法。13v 若有 `milliaria`，统一改为单 l。
3. **古典拼法**：采用 `octoginta`、`chorea`、`faecum`、`deprehendet`，即使 Favaro 本没改。符合规范第 3 节"统一为古典拼法"。
4. **Pleiadum Constellatio** 译作“昴星团”；Asterismus 译作“星群”。
5. **Nebulosa Orionis**：伽利略指的是猎户头部（λ Ori 附近）的星群，不是 M42。图题和正文改译为“猎户头部星云”，保留脚注说明。术语表相应更新。
6. **拉丁文书名**（如 *De systemate mundi*）用斜体，中文用书名号《》。

## 来自 B 组（f08v–f13v）

1. **f10v**：初版这一页只有图、没有页眉，所以本版也不印页眉，只保留叶码。需要在 preamble 里加一个无页眉的页面样式（主编做）。
2. **f09r Glaciales cyathi**：初版作 *Ciati*，维基文库录的 Favaro 作 *Gyathi*，疑为录入错误。采用古典拼法 `cyathi`，行末加 `% 1610: Ciati`。
3. **f11r “in secundis supra positis figuris”**：校对时对照 f09v–f10v 的图确定具体指哪几幅，加一条简短脚注。
4. **miliarium**：全书统一为单 l（同 C 组第 2 条），f13r、f13v 的 `milliaria` 要改。
5. **意大利里脚注**（f13r）保留；插图高度等重绘时再定。

## 来自 A 组（f01r–f06r）

1. **无页眉的页**：初版没有页眉的页（f01r 书名页、f02r–f04v 献词与出版许可、f05r、f10v 等全页图），本版同样不印页眉，只保留叶码。与 B 组第 1 条合并处理（主编做）。
2. **f05r semidiametros**：从 Favaro，保留脚注。**f05v oculorum**：校对时核对 Favaro 纸本／初版，确认删去是否正确。
3. **拼法**：f06r 作古典形式 `sexagies`，行末加 `% 1610: sexageties`。f01r 用 `patricio`，书名页同样按现代拼写，不照录原拼法。
4. **面积放大率脚注**：移到首次出现处 f06r（“近三倍、大九倍”）。f06v 的脚注改为只说明“四百倍＝线度二十倍”，或改成指向前注。
5. **待核实**：f04v 签名 *off. Con. Blasph. Coad.*（可能指威尼斯的“渎神罪执行官署”，Coad. = coadiutor 助理），以及 f06r 脚注“巴多维尔曾随伽利略学习”，交校对 agent 查证。
6. **Iuppiter 的双关**：神话语境（2v 列举英雄、*Iove digna proles*）译“朱庇特”，并加一条脚注说明拉丁文 Iuppiter 既指主神又指木星，伽利略借此暗指美第奇家族与木星卫星。天文语境一律译“木星”。
7. **f01r 版面、装饰首字母、页首花饰**：最后统一设计。

## 来自 D 组（f18v–f23v）

1. **插图位置**：采用 Favaro 本的做法，把图放在引出它的分句之后（“……排列如下：”之后），两栏同步。CONVENTIONS 第 2 节第 5 条“移到句末”据此修订。I.26 h.5 和 II.2 h.7 两幅也照此统一。
2. **1 月 24 日第六小时（f21r）**：文字说有两颗星，初版图只印了一颗。图照初版排，加一条脚注说明两者不一致。
3. **1 月 26 日 remota min. 30（f21v）**：译文照字面作“三十角分”，用脚注说明从图上看应为三十角秒。不要在正文里替伽利略改。
4. **拼法与缩写**：`vigesima` → `vicesima`（古典拼法）。观测记录里的天文单位缩写保留，但全书统一为 `min.`（角分）、`sec.`（角秒）、`hor.` 不缩写；`m. p.`、`min. pr.` 统一作 `min.`。中文照术语表。
5. **误印**：采用 Favaro 读法，行末加 `% 1610:` 注释；维基文库自身的录入错误按初版改正。这样处理正确。

## 来自 E 组（f24r–f28v）

1. **带恒星的木星图**（II.26 h.5、II.27、II.28 h.1、III.1、III.2）：主编给 `\jove` 加第四个可选参数，专门画恒星并在星旁标 *fixa*。校对时把这五幅图里的恒星从离线星列表移到这个参数。
2. **f27v sec. 20 / sec. 2**：校对时放大扫描核对初版，再与 Favaro 印本的读法比较。
3. **插图位置**：按 D 组第 1 条统一，图放在引出它的分句之后。只有放不下、会跨页的图才放在本页末尾（如 II.11 h.3），并加注释说明。
4. **拼法**：`pronunciare` 保留（古典拼法即如此）；`arcta` → `arta`（古典拼法）。初版误排的处理正确。
5. **空的 `\ZH`**（f24r、f28r 开头）：属于正常情况（跨页句子整句归前一页）。

# 校对阶段的决定（由主编在最后统一检查时执行）

## 来自 C 组校对（f14r–f17r）

1. **f16bv 星图尺寸**：重绘星图时再处理，必要时删去“星云状星”那条脚注。
2. **木星图星的大小**：维持规范的做法，伽利略文字说较大的星取 1.3。I.7 保持 1.3／1／1.3，全书一致。
3. **合写的数词**：按现代拼写分开写，`trigintasex` → `triginta sex`，`vigintiunas` → `viginti unas`，行末加 `% 1610:` 注释。全书统一（主编最后用全局检查确认）。
4. **`\folium*`**：初版没有页眉的页一律用 `\folium*`，不论有没有正文。f16br 的处理正确。
5. **犬星**：脚注加上“天狼星（大犬座 α）”。

## 来自 B 组校对（f07r–f13v）

1. **页间引用**：脚注里引用别的页，用与页眉一致的叶码格式，如“见 [9v]”。全书统一。
2. **插图高度**：重绘时按初版比例定（f10v 约 109 mm 和 95 mm）。
3. **f13v 插图**：留在 f13v，即初版所在的页，放在 “in puncto D.” 之后。不跟 Favaro 移到 f13r，因为本版按初版分页。
4. **ex + s 开头的词**：与 `exspecto`、`exstat` 保持一致，统一作 `exsisto / exsistere / exsistunt`（f07v、f11r 及全书）。
5. **f22r 的 vigesima**：由 D 组校对处理；主编最后全局检查确认。

## 来自 D 组校对（f17v–f23v）

1. **省略写法 `pr. 7`**（f20v，承前文 *minutorum primorum*）：统一作 `min. 7`。
2. **`trigesima`** → `tricesima`（古典拼法），与 `vicesima` 一致。
3. **复合序数词**：按现代拼写一律分写，如 `decimatertia` → `decima tertia`、`vicesimaprima` → `vicesima prima`，与合写数词的决定（C 组校对第 3 条）一致。
4. **角秒**：统一只写 `sec.`，`min. sec.` 改为 `sec.`（f19r、f19v、f22v 及全书）。

## 来自 A 组校对（f01r–f06v）

1. **pellucida**（f06v）：保留。这既是初版写法，也是古典拼法。
2. **oculorum**：只保留 LaTeX 注释，中文栏不加注。本版不设校勘记，这类纯文本校勘问题不出现在读者面前。
3. **f03r 三条脚注**：只要页面排得下就保留，三条都与献词的理解直接相关。
4. ***sua regia***：认可“从它的王宫”。
5. **书名页**：统一设计时再定。
