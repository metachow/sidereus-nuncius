## Substantive corrections

### Accuracy
- p030.01: 「次に示す順に配置した」 (as if Galileo arranged the stars) → 「三十六個を書き留めた。その並びは次のとおりである。」 (*in hunc ordinem dispositas* describes the stars).
- p032.06: 「木星が天文学の計算とは違って進んでいて」 (sense of *directus* lost) → 「木星が天文計算に反して順行しており」; footnote restored per ruling 4 (tables predicted retrograde, i.e. westward motion; only direct motion could have carried Jupiter east of the stars). The indirect question is now 「……どうして……見いだされうるのかと、戸惑い始めた」.
- p032.01: 「少なからず私を驚かせた」 → 「いささか私を驚かせた」 (*nonnullam admirationem* = some wonder); 「恒星のうちに数えるべきもの」 → 「恒星の一つ」.
- p034.02: ratio sentence rewritten so that it is unambiguous: 「中間の星と木星との距離は、中間の星ともっとも東の星との距離の三倍であった」.
- p034.03: translationese 「疑いなく私は決断し、定めた。天には……ある。」 → one sentence 「……と、いささかの疑いもなく断定した」; 「三つだけでなく四つ」 now depends on 「確かめられた」 as in the Latin (*observatum est … esse*).
- p038.01: 「すぐ上に描いた」 → 「次に描いた」 (*proxime depicta*; the figure follows).
- p038.06: 「わずか30秒ほど」 → 「せいぜい30秒しか離れていなかった」 (*vix 30*).
- p040.05: 「端の星」 → 「両端の星」 (*extremas*).
- p049.03: text said 30秒 while the note said the Latin has min. 30 → text now 「30分」 as in the Latin, note: 「原文は「30分」……30秒の誤りと思われる」, placed at the phrase.
- p057.01: 「前の図のように」 → 「次の図のように」 (*ut in proxima figura*; the figure follows). 「立っていた」 → 「あった」 (also p068.01).
- p060.02: 「一本の直線が引けた」 → 「一本の直線が貫いていた」 (*incedebat*).
- p061.02: *exigua satis* 「ごく小さく」 → 「かなり小さく」.
- p064.04: *medium … locum* was dropped → 「ちょうど中間の位置を占めていた」.
- p079.04: perpendicular rephrased so it is geometrically sensible: 「この惑星から、すべての惑星を通る直線に垂直に引いた線に沿って測ったもの」.
- p080.01: *ad unguem congruere* 「まったく一致」 → 「寸分違わず一致」; note reworded (「……天文表をいう。たとえば……エラスムス・ラインホルトの『プロイセン表』（1551年）がある」).
- p081.02: 「木星に似た間隔を保って」 (misreading of *consimilibus interstitiis*) → 「似たような間隔を保って」; 「疑えないはずである」 → 「誰も疑うことができない」; *interea dum* → 「しかもそのあいだに」.
- p081.04: 「先に記した往復を注意深く考えれば」 → 「先に記録した回帰を注意深く検討すれば」 (*praeadnotatas reversiones*).
- p081.05: 「……一周するので」 (causal, not in the Latin) → 「月がただ一つ地球のまわりを回り、しかも両者がそろって一年で太陽のまわりを一周するということにはひどく心を乱され」; 私たち → われわれ (also p081.11).
- p081.06: 「極小の回転」「自分自身の二倍以上」 → 「ごく小さな回転」「ときに別のときの二倍を超える大きさ」 (*semetipsis plusquam duplo maiora*).
- p081.11: note 「14葉裏を参照」 → 「[14v]を参照」 (ruling 1); last sentence joined (「運ばれていて、……見えるのであろう」) so the hypothetical covers the whole.
- p081.12: translationese 「時間の乏しさが妨げる。……近く待ってよい」 → 「時間が足りず、これ以上先へ進むことはできない。公正な読者は、近いうちにこれらについてさらに多くを期待してよい。」
- p031.02: *per duos proxime menses* 「およそ二か月」 → 「この二か月のあいだに」; 「取りかかっていただきたい」 (keigo) → 「取り組むよう呼びかける」; subject われわれ as in the Latin (*nobis*).

### Log formulas (ruling 2), unified across both files
- Hours without *noctis*: 「0時30分」「1時15分」「2時」 etc. (p043–p049) → 「第0時30分」「第1時15分」「第2時」; *ab occasu*: 「日没後0時30分」 → 「日没後第0時30分」 (p040, p041, p046), 「日没後1時」 → 「日没後第1時」 (p050).
- Entry heads: part 5 had 「3日、第7時、……」; now both files 「N日、第N時には、……」 (「夜の第N時」 only where the Latin has *noctis*).
- *zodiacus* was rendered 黄道 (「黄道の経度に沿って」「黄道の走る向き」): now 獣帯/黄道 as in the Latin — p033.03, p033.04, p045.04, p046.02, p055.05, p061.03, p068.01, p075.05 → 「獣帯に沿って」; p035.02, p066.04, p071.01, p074.02, p076.02 → 「黄道に沿って」.
- *ad unguem*: 「まったく正確に」「正確に」「まったく同じ直線上」 → 「寸分違わず」 (p038.05, p042.02, p047.04, p054.02, p055.02, p057.01, p064.04, p066.04, p070.02, p071.01, p073.02, p074.02, p076.02, p080.01).
- Weather: p037.01 「天気が曇りであった」 → 「空は曇っていた」; 「雲におおわれていた」 → 「雲に覆われていた」 (p067.01, p074.01, as p032.07).
- Figures: 「付した図に見えるとおり」「付した図が示すとおり」「図のとおり」 → 「添えた図に示すとおりである」 (*apposita figura / descriptio*) and 「図に示すとおりである」 (*ut in figura / descriptione*).
- Chains: 「これと二番目の星との間は1分」 etc. → 「二番目の星はこの星から1分、……」; *occidentalior* in chains 「さらに西の星」 (p042.02, p055.02, p055.05, p056.01).
- *media stella*: part 5 中央の星 → 中間の星 (as part 4); 中央 kept for *medium locum / mediam sedem*. *orientalior*: 「もっと東の/さらに東の」 → 「もっとも東の」; where only one star is east (p036.03) 「東の星」.
- *observatio/observare* in the discovery and log: 観察 → 観測 (part 5 already 観測).

### Style and notation
- Ratios and counts in kanji per guidelines: 2倍/3倍 → 二倍/三倍; 21個/36個 → 二十一個/三十六個 (p030 already had 四十).
- 最も → もっとも; 「1時間ごとの違い」 (p034.03); minor wording elsewhere (p033.02, p042.05 「はじめは」 dropped, p043.04, p045.08, p051.01 「雲にさえぎられて」, p053.01 「最後の日」 → 「末日」, p078.02/p079.03 「持ち上がっていた」 as elsewhere).

## Final list of log formulas
- Head: 「12日、夜の第1時には、」 (*hora noctis*); 「22日、第2時には、」 (*hora* alone); 「17日、日没後第0時30分には、」 (*hora ab occasu 0, min. 30*); 「21日、第0時30分には」; 「第5時半」 (*quinta cum dimidia*); 「第5時ごろ」 (*proxime / circa*). Later in the entry 「第3時には」. Month once: 「2月1日」「3月1日」; *die ultima* = 「末日」.
- Distances: 「東の星は木星から3分離れていた」; 「1分30秒」; *min. 0, sec. 40* = 「40秒」. Chain: 「もっとも東の星は次の星から3分、この星は木星から40秒離れていた。木星は西の次の星から4分、この星はさらに西の星から6分離れていた」.
- *in eadem recta* = 「同じ直線上にあった」; *ad unguem* = 「寸分違わず」; *exquisite / praecise / adamussim* = 「正確に」.
- *secundum zodiaci longitudinem / ductum* = 「獣帯に沿って」; *secundum eclipticae longitudinem / ductum*, *secundum eclipticam* = 「黄道に沿って」; *eclipticae parallela* = 「黄道に平行な」.
- *sub Iove latitare* = 「木星の陰に隠れる」. *media* = 中間の星; *orientalior* = もっとも東の星; *occidentalior* = もっとも西の星 / (in chains) さらに西の星; *Iovi proxima* = 木星にもっとも近い星; *vicinior/propinquior* = 近いほうの星; *sequens* = 次の星.
- Weather: 「空は曇っていた」; 「空は雲に覆われていた」 (*nubibus obductum*).
- Figures: 「添えた図に示すとおりである」 (*apposita*); 「図に示すとおりである」 (plain); figure following a colon: 「次のようであった」「次の図のように」.
