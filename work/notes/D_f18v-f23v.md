## 译法（新增）

- 角度：`min. 2` 译作“两角分”；`min. 0, sec. 40` 省去“零角分”，只写“四十角秒”；`min. sc. vix 30` 译作“不过三十角秒”。
- 时刻：序数词的照术语表（hora tertia → 第三个小时，hora noctis secunda → 入夜后第二个小时）；写成数字的 `hora 1, min. 15` 译作“一时十五分”；`hora 0, min. 20 ab occasu` 译作“日落后零时二十分”；`hora 2` 译作“二时”。
- secundum zodiaci ductum → 沿黄道带的走向；secundum eclipticam → 沿黄道；sub Iove latitantes → 藏到了木星后面（与 f17v 一致）。
- Die ultima → 一月的最后一天。
